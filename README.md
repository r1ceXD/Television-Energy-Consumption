# Television-Energy-Consumption

Introduction: The purpose of the use of AI is to help with any skills gaps that I have regarding programming.

Tool Description: GitHub Copilot. GitHub Copilot is an extension of Visual Studio Code that can generate code in my local files.

Usage Details:

Prompts Used: 
-can you help with generating a nav bar for 3 pages, and a footer

-can u add to my javascript file with the function to switch between web pages instead of using html

Outputs Received:
-Received three html files and a css file for appliances. Some code was not relevant to the topic

-Received a javascript file with the function to switch web pages

Modifications Made:

Some lines of code was not relevant and unnecessary. Irrelevant and unnecessary content, as well as code that I could not understand after long periods of time trying to understand were removed. The removed lines of code were replaced with content that I understood myself.

Reflection:

AI has made a lot of progress, but with some drawbacks. One of them being that some lines of code could not be understood by me. So either I try to fully understand the generated code, or I just removed the code entirely. Using AI has improved the way I code, as I get to learn about the new code that was generated as I try to fully understand them through online sources.
